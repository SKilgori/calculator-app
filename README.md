# Calculator App

[![CI](https://github.com/SKilgori/calculator-app/actions/workflows/ci.yml/badge.svg)](https://github.com/SKilgori/calculator-app/actions/workflows/ci.yml)
[![Language](https://img.shields.io/github/languages/top/SKilgori/calculator-app)](https://github.com/SKilgori/calculator-app)

A simple, accessible calculator web app built with plain JavaScript, HTML and CSS.

Demo
- Live demo: https://skilgori.github.io/calculator-app/

Quick overview
- Purpose: A small calculator demonstrating DOM manipulation, keyboard support, and clean UX.
- Tech: JavaScript (ES), HTML5, CSS3

Features
- Basic arithmetic (+ − × ÷)
- Keyboard support
- Clear / backspace
- Responsive layout for desktop and mobile

Getting started

1. Clone
   git clone https://github.com/SKilgori/calculator-app.git
   cd calculator-app

2. Install
   npm install

3. Run (development)
   npm run start

4. Build (production)
   npm run build

Development & code quality
- Lint with ESLint: npm run lint
- Format with Prettier: npm run format
- Run tests (if added): npm run test
